# D044：通用卡片不证明简历发送，消费核对语义依据

- **日期 / 状态：** 2026-10-08 / 已实现；真实界面待用户验收。
- **来源与问题：** 用户指出未发送简历的岗位被统计为已发送，并授权只读核对该会话。单次定点历史读取确认，通用岗位相关卡片也使用此前识别为发送的 `type=4 / bizType=317 / body.type=16 / style=3 / templateId=1`、单文章和对端发送结构；本次材料没有已确认的系统发送文字。模板相等不能独立证明发送。
- **决定：** 移除结构单独推断 `request_sent`，类型 4 回到既有纯卡片观察。平台精确文案“附件简历请求已发送”仍表示已发送，不按“请求”字面重新解释。新采集保留最小可重算语义依据，正式消费先判断含义，再执行既有账号、会话、岗位及人工保护规则。
- **旧材料与兼容：** 私有快照与交付批次升至 v5、历史检查点升至 v3，兼容旧快照/批次 v1–v4 与检查点 v1/v2。旧快照有类型 4 时只可认定卡片，保留原分类及观察/事件/事实/应用 ID；旧队列 `request_sent` 缺可核对依据时等待 `resume_semantics_missing`，不因升级取得可信地位。新依据进入批次摘要，不改变稳定事件身份；未知字段或未来版本继续拒绝。
- **历史与人工决定：** 不批量撤销已应用历史。用户指认且满足既有安全条件的错误观察，通过版本化服务命令否决并撤回其单独造成的自动变化；原始事实保留，补录和重放不能恢复同事实应用。人工字段、人工忽略、删除、同步冲突及恢复缺口保持。
- **取舍与隐私：** 仅修改新分类会留下旧队列继续误用的路径，因此增加消费端语义依据检查。未知旧材料可能等待，避免再把通用模板当作发送证据；不扩大为停止全部简历自动联动。依据只含类型、固定字段路径与已识别状态文字，附件文件名替换为固定占位，不保存原始响应、正文、凭据或简历。诊断取样使用原有串行预算，一个联系人请求及一页历史，临时取样代码已移除，脱敏依据仅保留在本机。
- **替代关系：** 修正 D025/D031 下的模板识别实现假设，补充 [D033](0033-boss-import-convergence.md) 的消费校验，沿用 [D043](0043-boss-observation-only-archive.md) 的纯存档处理；保留 [D030](0030-reject-misattributed-resume-observation.md) 的文案含义、[D034](0034-boss-cross-observation-attribution.md)/[D035](0035-boss-conversation-association-application.md) 的归属规则。
- **运行与验收：** 应用 0.10.15、规则 v12；正式共享数据 v4、工作区 v3、备份 v2、服务协议 v1 及正式存储保持，无整库迁移。服务重启不恢复 BOSS 跟踪；合成回归和真实单会话核对分别记录，真实界面待用户验收。
- **重新评估条件：** 取得可以独立区分发送确认与其他卡片的稳定平台字段，或真实样本否定现有精确状态文字含义时，重新评估对应识别规则；不根据模板、方向或附件存在推断。
