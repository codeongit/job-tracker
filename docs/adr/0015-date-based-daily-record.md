# D015：每日记录按业务日期查询，不还原历史快照

- **记录日期 / 状态：** 2026-09-11 / 已由 [D016](0016-two-entries-unified-detail.md) 替代；独立页面与刷新默认今天的安排不再适用，下述业务日期及去重语义保留。
- **来源：** 用户要求分天查看，并确认独立“每日记录”页、综合记录、首次联系日及只读查询。
- **问题：** 今日页服务于当前决策，只把待办粗分为到期、未来和无日期，无法回看某一天的计划、实际结果、沟通及首次联系。
- **决定：** 新增独立的只读每日记录页，并按岗位合并当天的首次联系、沟通和行动。计划按 `dueAt`，完成和取消按本地日期下的 `completedAt`，沟通按 `activities.date`，岗位按 `appliedAt` 查询。导入生成的同日“首次联系”活动折叠到首次联系里程碑；跨日完成分别出现在计划日与实际日，同日只出现一次。
- **约束：** 只显示未删除且有对应日期的记录；已结束岗位仍可出现在首次联系日。岗位阶段明确标为当前阶段，不把当前记录解释为历史快照。日期选择只保留在当前页面会话，刷新后回到今天。不增加共享字段或版本。
- **重新评估条件：** 需要月历、日期范围、无日期记录整理，或需要还原任意日期的完整招聘状态。
