# D017：真实浏览器相关测试由人工负责

- **记录日期 / 状态：** 2026-09-14 / 有效。
- **来源：** 用户明确要求“浏览器我来测试吧”，并要求记录“当前项目真实浏览器相关测试由人工负责”。
- **问题：** 明确长期维护中的测试责任，避免开发交付因浏览器启动、权限和环境排查而反复耗时。
- **决定：** 真实浏览器相关测试由用户人工负责，包括交互、移动端、中文输入法和 Playwright/headless 回归。代理负责实现、相关非浏览器测试、静态与格式检查，并提供简短的人工验收项。没有人工反馈时，如实标明“待人工验收”。
- **约束：** 除非用户后续明确委托，代理不启动、连接或控制浏览器，不安装测试浏览器、不申请浏览器测试权限，也不尝试其他浏览器途径。代理本地不运行包含浏览器测试的 `pnpm verify`，改为按范围运行非浏览器测试、`pnpm check` 和 `pnpm format:check`；发布前运行完整 `pnpm test`。纯文档修改只检查格式、链接与差异。
- **兼容：** 保留现有浏览器脚本和 CI 配置；人工或 CI 可以运行完整检查。CI 结果单独报告，不能替代人工验收。浏览器回归仍使用隔离环境与合成数据，不操作用户私有工作区。
- **替代关系：** 调整 [D008](0008-lightweight-static-architecture.md) 的测试执行分工，保留检查能力与隔离要求；[D010](0010-ci-separate-deployment.md) 的 CI 触发安排不变。
- **重新评估条件：** 用户明确委托代理执行某次浏览器测试，或明确要求调整长期测试分工。
