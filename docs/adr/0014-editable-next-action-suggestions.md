# D014：下一步表单提供可编辑的状态建议

- **记录日期 / 状态：** 2026-09-11 / 有效。
- **来源：** 用户要求新增行动提供默认值，例如简历发送后询问面试安排；计划日期提供“2 天后”等默认选项。规则边界为实现选择。
- **问题：** 每次安排下一步都要重复输入常见行动和计算日期，完成“发送简历”后也不能顺着当前状态快速建立下一项任务。
- **决定：** 没有待办时，使用结构化的招聘阶段、简历状态和面试活动生成可编辑的行动预填，计划日期默认是本地日历 2 天后；同时提供今天、明天、2 天后、1 周后和不设日期快捷项。
- **原因：** 预填减少重复操作，仍让用户在提交前核对文案和日期。按结构化状态判断比扫描备注或原始文字稳定，也符合不推断缺失信息的导入原则。
- **约束：** 建议本身不写入正式数据或草稿，只有用户修改或明确提交才保存。已有待办、已结束或暂缓时不预填；已恢复草稿及当前输入优先。未修改的默认值遇到同步或跨标签状态变化时重新计算，提交事务再次核对当前状态，不能据旧建议创建重复任务。日期按本地日历日进位，不按固定毫秒数换算。不增加共享数据字段或版本。
- **重新评估条件：** 需要按个人习惯定制规则、同时规划多项行动、自动提醒，或现有阶段不足以表达面试轮次。
