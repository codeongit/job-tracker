# D019：BOSS 简历发送联动消息和招聘阶段

- **记录日期 / 状态：** 2026-09-14 / 有效。
- **来源：** 用户要求选择简历已发送时，消息设为已读、招聘阶段改为沟通中，并提供其 BOSS 使用流程作为依据。渠道范围与不回退规则为实现选择。
- **决定：** BOSS/BOSS直聘岗位的简历已发送或对方已接收时，消息联动为已读，已触达（含旧待联系）推进至沟通中；沟通、面试、Offer、已结束阶段保留。编辑表单即时显示，明确保存才生效；记录发送简历、核实已发送和完成标准发送行动复用同一规则。“对方已接收”不因再次记录发送而降为已发送。
- **原因：** 一次操作维护相互关联的状态，减少漏改和矛盾；后续阶段已包含沟通进展，不应回退。
- **约束：** 仅被索要、待处理、取消行动和其他渠道不触发联动。渠道匹配忽略大小写和空格，不按备注推断。保留草稿、中文输入和并发保护；不自动提交，不在读取、导入、同步或备份恢复时批量修改历史数据，不改变数据格式或本轮版本号。
- **关联关系：** 扩展 D018 的表单状态规则，保留其旧值兼容；D013 的核实日期、去重和任务取消语义不变，D017 的人工浏览器测试分工不变。
- **重新评估条件：** 用户的 BOSS 操作流程变化，或明确要求其他渠道也采用联动规则。
