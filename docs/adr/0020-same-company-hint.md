# D020：新增岗位时非阻断提示同公司记录

- **记录日期 / 状态：** 2026-09-14 / 有效。
- **来源：** 用户要求新增相同公司时给提示，并确认使用表单内非阻断提示及规范化后的完全匹配。
- **问题：** 手动新增岗位时无法得知同一公司已有记录，容易重复录入同岗位，也不便发现这家公司已有的其他机会。
- **决定：** 新增岗位及恢复新增草稿时，在公司输入框下显示匹配总数及最多 3 个现有岗位和当前阶段；公司与岗位同时匹配时提示“可能是重复岗位”，只有公司匹配时提示“该公司已有其他岗位”。提示不阻止保存，不增加确认弹窗；编辑已有岗位不显示。
- **匹配规则：** 公司名经 Unicode NFKC、首尾空白清理、连续空白合并和英文小写转换后完全相等才匹配；不删除“有限公司”等后缀，不使用包含或模糊匹配。只检查未删除记录，包含已结束岗位；同岗位优先，其余保持现有顺序。岗位为空时不标记同岗位。
- **交互与兼容：** 公司和岗位在中文组合输入提交后更新专用提示区域，不替换表单节点；跨标签或同步更新后重新计算。提示不进入 FormData 或草稿，不新增数据字段，不修改同步、备份和草稿格式，不提升本轮版本号。D017 的真实浏览器人工验收分工继续有效。
- **重新评估条件：** 公司名称存在大量别名导致精确匹配频繁漏报，或需要合并岗位、公司维度详情及强制防重复。
