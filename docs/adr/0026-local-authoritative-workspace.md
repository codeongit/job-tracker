# D026：本机权威工作区与显式持续跟踪

- **记录日期 / 状态：** 2026-09-21 / v0.8.0 已实现；真实首次迁移、后台任务页和页面关闭录入待用户人工验收。
- **来源：** 用户要求减少反复选标签、失败限流、重启导入及无效待核对，明确要求网页关闭也能完成采集和正式录入；确认保留手机/公开静态版独立编辑并手动 GitHub 同步、本机服务不登录自启、手动开始持续跟踪，且启动服务和重启均不自动访问 BOSS。
- **决定：** 继续单仓模块化，不另建独立产品。本机服务成为正式工作区单写者，保存不可变完整 JSON 提交、内容摘要和原子 HEAD；浏览器 IndexedDB 作为本机缓存，草稿仍留浏览器。静态模式保留 IndexedDB 正式编辑。两模式只手动云同步，本机失联不静默退回静态写入。
- **生命周期：** 服务 `start/status/stop` 与跟踪 `start/run/pause/resume/stop/recover-page/status/doctor` 分开。服务启动只读取/处理本地材料；明确开始后复用 CDP 任务后台页，上一轮结束 2 分钟后下一轮。同轮重复触发合并，不补跑休眠期间轮次；生命周期控制串行化，`start/resume/recover-page` 在操作浏览器前等待调用前轮次收尾，暂停/停止不会被晚到结果覆盖。重启丢弃运行授权，保留预算、检查点和暂停诊断。
- **预算：** 取消全命令 45 分钟/每日 16 次限制；以账号实际动作计历史请求每轮 20、每滚动小时 60，DOM 每轮最多 1 且间隔至少 30 秒，详情每轮最多 20 且导航间隔至少 10 秒，DOM/详情合计每滚动小时 60。平台轮次前保守预留可用上限，可信结果返回后改记实际用量；已发出失败或结果未知的动作仍计数，本地预览、排队和可证明发出前的断链不计平台额度。每轮必须消费控制器签发且绑定精确额度的单次票据，兼容命令不能绕过调度。预算不是平台安全承诺。
- **事务与安全：** 固定本机 API v1、Host/Origin/会话/协议校验；命令包含稳定 commandId 与 expectedRevision，完整校验后 CAS 提交。网页只可调用白名单业务记录编辑、同步配置、冲突、同步确认、恢复和来源绑定命令，不能通用覆盖整库或改写来源账本。本机 SSH 同步由真实读取签发绑定 revision、远端 SHA 和计划摘要的一次性事务，精确 PUT 前重新核对写者、目标、基线及 pending，成功后才能确认；同步确认与冲突暂存只提交事务 ID，不接受网页提供 remote/captured/uploaded 整库，已有基线时远端缺失在服务端停止。HEAD 已原子替换但目录同步短暂报错时只重试持久化屏障；持续失败隔离写者且不回执，重启后按实际 HEAD 核对。业务结果和处理标记同一提交成功后才回执，丢响应可幂等确认。未知格式、损坏提交链、外部 HEAD 改动和其他活跃写者拒绝写入；服务 stop 校验实例归属，不强杀陌生 PID。
- **业务与冲突：** 共享数据 v3 保留 sourceEvents，增加 sourceFacts/sourceApplications，分离事实与业务应用；事实身份只取平台、账号、会话、消息 ID 和事实类型，不取岗位名、联系人、采集时间或规则版本，不同回执状态作为不同事实。缺稳定消息 ID 时只保存等待证据，不创建岗位或语义事实。旧事件 ID 原样保留并建立语义映射，迁移不重演历史状态。人工修改含主动清空保留所有权。缺依赖等待、人工保护和真实歧义分别记录；已知或重基时新发现的岗位冲突只阻塞有关岗位及依赖，同批无关岗位及人工编辑继续并重基 pending，直接触碰现有 conflict key 则拒绝；远端单方面转移本服务已拥有的 BOSS 账号形成身份冲突，不能静默解除队列绑定。账号身份、全局记录或无法隔离的结构冲突才停止。坏批次隔离，已知账号故障阻止该账号后续依赖，不能忽略顺序强行跳过。
- **迁移：** 工作区升 v3，备份外层保持 v2，本机磁盘/协议各为 v1。用户在原浏览器先生成包含草稿、数量与 SHA-256 的完整迁移备份，再明确确认初次迁移；缺少来源、全空来源或备份后记录/草稿变化均停止。服务保存原始工作区，将本机 data、pending 本机候选与冲突中两个可选 live 结果的账号归属迁移为稳定服务工作区 ID；base、pending remote 数据集与冲突 base 保留云端证据，供首次同步上传新身份而不被旧远端选择反向覆盖。已有服务工作区不能被另一浏览器缓存覆盖，另一浏览器有不同 IndexedDB 时必须先完整备份再明确切换，并发初始化不能接受另一来源或任意 409 作为成功。旧静态客户端需在首次 v3 同步前关闭/升级，协议不能远程撤销未接触新格式的旧客户端。
- **故障与恢复：** 登录、验证码、身份/目标/结构异常立即暂停，暂时故障连续三轮暂停；无平台请求副作用的调试通道传输中断只按持久的 2/10/30 秒最多三次重连。已发出且结果未知的历史请求按一次计数，不在重连中重放，等待页面内超时后由下轮从持久页码继续；详情、DOM 等副作用命令同样不自动重放。保留深分页会话/页码续点、完成项及最小材料，任务页恢复需明确触发，不刷新用户原页，不自动登录。停止/暂停不清空预算。恢复旧备份不能仅凭队列回执断言已录入；来源缺口只允许用户明确、带当前 revision 重放，且不复活删除记录。
- **备选与取舍：** 不引入 SQLite；当前单机单写者、规模与整工作区同步适合不可变 JSON。完整提交简单可审计但占用更多磁盘，尚未自动裁剪历史；达到体积/频率瓶颈、多人写入或复杂查询需求再评估数据库。浏览器提交最小白名单业务变更，服务重新校验并生成完整不可变提交；不接受无条件文件替换或任意脚本执行。
- **保留边界：** 平台只读，不发送、不投递、不触发云端自动同步，正常链路不依赖模型；日期仍按 D023/D024，简历白名单与联动按 D025，真实浏览器验收按 D017。没有 OS 定时任务或开机自启。
- **替代关系：** 替代 D003 的本机 IndexedDB 权威角色、D022/D023 的页面消费与单轮运行限制、D023/D024 的旧预算，以及 D005 在本机模式下的整库编辑冻结；自动导入与人工业务编辑均按岗位及依赖隔离，并补充 D012 的关页正式历史。上述条目其余有效语义保留。
- **重新评估条件：** 需要自动云同步、登录自启、远程服务、平台写操作、多用户/多写者、历史自动裁剪，或需要扩大已确认状态白名单；均应另作明确决定。
