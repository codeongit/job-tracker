# D022：招聘自动化只读、低频串行与故障现场保留

> 2026-09-21：只读、脚本和故障材料边界继续有效；以下“关页积压、仅单轮手动触发、未启用周期”等首版描述已由 [D026](0026-local-authoritative-workspace.md) 替代。

- **记录日期 / 状态：** 2026-09-18 / 有效；首版接入由 [D023](0023-boss-private-queue-integration.md) 落实，周期调度仍未启用。
- **来源：** 用户提出自动跟踪并录入投递状态，明确要求正常人的操作节奏、招聘平台只读、不回复或执行计划外操作、优先脚本执行、异常保留必要现场后再介入。
- **决定：** 将这些边界固定为 [自动化操作规约](../AUTOMATION_POLICY.md)。正常链路采用确定性脚本；平台动作限于已确认读取范围，故障停止扩大操作并保留最小必要的私有诊断。
- **原因：** 让后续运行可重复、可审计并限制浏览器操作；排障材料与检查点使修复不必反复操作真实账号。
- **接入实现：** [BOSS 接入说明](../BOSS_AUTOMATION_DESIGN.md) 使用私有事件队列、工作台事务入库、精确来源关联与人工待核对；工作台关页时先积压，不绕过 IndexedDB。首版只支持人工命令触发采集，周期调度仍未启用。
- **约束：** 只读限制针对招聘平台，本机工作台录入须遵守明确的字段规则、备份、并发和迁移边界；未知/送达不能映射成平台确认的未读；模型不直接提交招聘阶段。保留 D003 的手动云同步、D007 的格式升级、D009 的不推断缺失信息及 D017 的人工浏览器验收。
- **替代关系：** 新增操作规约，不替代已有数据、同步和浏览器测试决策。若实现涉及调整 D018/D019 的状态语义或重复导入覆盖规则，应另记决定。
- **重新评估条件：** 用户要求扩大平台动作、采集历史、工作台关页后立即写入正式记录、自动云同步或更改阶段推断规则。
