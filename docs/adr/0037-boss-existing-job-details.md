# D037：复用精确匹配的本机岗位资料

- **日期 / 状态：** 2026-10-04 / 已实现；真实界面待人工验收。
- **来源：** 用户指出等待观察的入口只跳到岗位列表，且许多岗位已有资料，要求改善核对并自动补齐。
- **决定：** 普通观察缺标题时，不限于已有来源绑定。已绑定当前工作区的账号下，岗位 ID 和平台链接一致、唯一现有岗位具有完整公司和标题、公司不矛盾、岗位未删除且没有其他账号或矛盾绑定，可建立不持有自动字段的来源绑定并完成处理。多个目标（含删除记录）或明确矛盾仍拦截；没有匹配资料继续等待。原始观察不补写为平台证据，岗位人工字段不改变。
- **核对入口：** 无唯一绑定时，在观察卡片内展示按岗位 ID 或同公司找到的本机候选，打开现有详情而不是跳转整个列表。候选只是导航建议，明确区分岗位 ID 匹配和同公司候选。点击时重新读取数据并核对候选有效性；关闭详情返回原观察位置和选择。
- **边界：** 同公司不能用于自动绑定。已有本机岗位不能代替简历观察的会话及参与者依据；简历归属、跨岗位检查、人工否决、持续忽略、删除和同步冲突规则不变。不新增平台采集。
- **兼容：** 应用 0.9.19、应用规则 v8，共享数据仍为 v3。旧队列、等待项和恢复均经共用处理链路；磁盘回执不替代事实存在性检查。
- **替代关系：** 扩展 [D036](0036-boss-waiting-observation-ignore.md) 的普通观察补资料条件；保留其人工忽略决定与 [D035](0035-boss-conversation-association-application.md) 的简历归属规则。服务重启不恢复跟踪授权。
