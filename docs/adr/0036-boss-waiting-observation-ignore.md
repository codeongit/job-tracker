# D036：处理历史等待项并允许人工忽略观察

- **日期 / 状态：** 2026-10-04 / 已实现；真实界面验收待用户确认。
- **来源：** 用户确认历史等待项处理计划，选择一轮正常补录、逐条展示支持多选，以及持续忽略同一观察。
- **决定：** 普通观察缺岗位标题时，账号、岗位 ID、链接与唯一有效绑定一致且已有完整岗位资料，可完成关联。原始缺失信息不改写为平台证据；明确矛盾仍拦截，不覆盖人工字段或放宽简历归属。
- **人工忽略：** 仅对当前有效 BOSS waiting 来源应用提供多选确认。复用 protected 与固定原因 user_ignored_unresolved_observation，保留事实、观察和提交历史，不确认归属、不改变岗位。后续同一事实补证或重放不能自动恢复应用，新消息仍独立判断。被忽略的原始观察仍参与跨岗位异常检查。
- **取舍：** 选择持久人工决定，而非暂时收起后自动应用。缺失依据无法保证能补齐；用户可以结束旧材料的处理负担，同时保留审计。未选择自动批量清空或反复补录。
- **交付：** 通过单写者固定命令、预期版本与持久幂等键原子提交；同步冲突阻止忽略，旧状态不接受操作。详情单独计数“已忽略”，不混入人工字段保护。本轮不增加撤销入口。
- **兼容与恢复：** 共享数据 v3、原事实和事件 ID、私有协议保持不变；应用规则 v7。备份和手动同步携带来源应用决定。恢复旧备份仍可能回到忽略前状态，按已有恢复与缺口核对规则处理，磁盘回执不能证明当前事实存在。
- **替代关系：** 部分调整 [D033](0033-boss-import-convergence.md) 的只读异常交互边界，增加明确的人工忽略；保留 [D034](0034-boss-cross-observation-attribution.md) 和 [D035](0035-boss-conversation-association-application.md) 的归属及人工保护规则。
- **运行边界：** 一轮既有预算内补录不保证覆盖全部旧消息，不自动循环或启动持续跟踪；剩余项由用户选择确认。服务重启不恢复跟踪授权。

- **后续调整：** [D037](0037-boss-existing-job-details.md) 扩展普通观察的资料复用范围，允许在完整且唯一的精确本机岗位上建立非自动字段绑定；人工忽略规则保留。
