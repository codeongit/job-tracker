# D021：全部日期下岗位按添加时间倒序

- **记录日期 / 状态：** 2026-09-17 / 有效。
- **来源：** 用户指出新增岗位没有出现在列表最前，期望按添加时间查看；旧记录的兜底规则为实现选择。
- **问题：** 全部日期下沿用数据数组顺序，手动新增追加在末尾，且同步序列化可能改变数组顺序，不能代表添加先后。
- **决定：** 全部日期下按 `createdAt` 实际时间从新到旧排列，再按每页 10 条分页；编辑和沟通不使旧岗位置顶。指定日期继续使用当天事件排序。
- **约束：** 缺少或无效添加时间的旧记录排最后，同时间及无有效时间记录保留原相对顺序；不以首次联系日或更新时间推断添加时间，不改写源数据及同步、备份、草稿格式。筛选、页码与详情上下文保留规则不变；真实浏览器仍由人工验收。
- **替代关系：** 调整 [D016](0016-two-entries-unified-detail.md) 查询方案中全部日期沿用数据顺序的安排；保留指定日期的事件排序及其他交互规则。
- **重新评估条件：** 用户需要主动切换排序方式，或明确要求为历史导入记录补充添加时间。
