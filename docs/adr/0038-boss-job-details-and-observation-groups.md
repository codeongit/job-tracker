# D038：详情页补齐岗位与消息汇总展示

- **日期 / 状态：** 2026-10-06 / 已实施代码；真实界面待人工验收。
- **来源：** 用户确认《BOSS 岗位补齐与观察展示整理》实施计划；明确岗位详情页为资料依据，猎头与用人公司可不同，并要求本轮实现岗位及未关联观察的关闭标识。
- **决定：** 岗位名称及用人公司采用岗位 ID、规范链接一致的详情证据。聊天公司保留为招聘方，不单凭名称差异拦截。详情证据之间、链接、账号或目标矛盾仍拒绝；匿名公司不推断，人工字段不覆盖。统一链接解析支持波浪号并移除查询及片段。
- **人工资料处理：** 服务以版本比较和幂等命令原子处理指定普通观察，应用结果为 `no_effect / user_confirmed_job_details`，保存人工目标与规范岗位身份。原始观察不改写；此映射不能用于验证简历归属，也不绕过跨岗位、否决、忽略或删除检查。不新增人工补齐界面。
- **展示：** 同账号、会话、稳定消息汇总一张卡片，事实保持独立。等待计数按消息汇总；勾选展开为可忽略等待应用 ID，确认同时显示消息及观察数量。冲突优先，缺稳定消息身份单独展示。
- **平台状态：** 岗位与应用记录使用未知、招聘中、关闭，另存人工依据时间。无正式岗位的观察也可保留关闭标识；明确关联更新原子传播。状态冲突提示核对，重放不能覆盖人工状态。关闭不改变个人跟进阶段，不清除资料等待，不删除或忽略历史；标题读取失败不是关闭依据。
- **兼容：** 应用 0.10.0、规则 v9、共享数据 v4、私有批次 v4。工作区外层 v3、完整备份外层 v2 保留；迁移覆盖 data/base/pending 及冲突各侧，保留原工作区，旧队列无新依据不取得详情可信地位。事件、事实、应用 ID 保留。
- **替代关系：** 调整 [D037](0037-boss-existing-job-details.md) 的公司一致条件及卡片粒度，扩展 [D036](0036-boss-waiting-observation-ignore.md) 的分组选择；保留 [D035](0035-boss-conversation-association-application.md) 简历归属规则。对先前等待项规格的只读补齐与关闭延期安排，以本决定为准。
- **验收：** 非浏览器测试覆盖详情身份、猎头代招、人工补齐重放、批量原子保存、分组计数、状态冲突、备份及同步。服务重启不恢复 BOSS 跟踪，不新增平台访问；界面操作仍由用户验收。
