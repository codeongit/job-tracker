# 01 简短本地记录与可追溯反馈

## 来源与决定

来源为[流程精简规格](../../../docs/specs/workflow-simplification.md)的 S1、S3–S6，以及“简短记录与规格保存”一节；规格基线为 `cd117913753e341d5c47adc2085502a0f5690b52`。

用户要求降低现有任务套件的固定成本，同时保留复盘材料。每次交付仍需一条简短记录，但不强制任务 UUID 或起止时间；正式规格随 Git 保存，交付记录保存在被 Git 忽略的本机 Markdown。最新 S6 已覆盖早期保存位置选项，即使已有 Issue／PR，也不默认追加记录、规格或链接。

拆单时的基线行为可从原任务记录试行（见提交 `f1a94a3` 的 `docs/agents/change-workflow.md`）、[实施入口](../../../.agents/skills/implement/SKILL.md)、[诊断入口](../../../.agents/skills/diagnosing-bugs/SKILL.md)和[复盘入口](../../../.agents/skills/retro/SKILL.md)核对：当时固定登记 UUID、开始时间和较完整的交付字段，复盘与交接依赖这些记录。需改变的是默认填写负担，不是抹去可追溯性。没有阻断性的待决设计事项。

## 交付结果与约束

交付一条从本地简短记录到后续反馈、个案复盘和跨会话恢复的完整路径。共用规则定义最小内容：目标与取舍、结果与版本、验证与限制、实际发生的后续反馈；简单任务可各用一句话。其他入口引用同一约定，不再另要求全量评估模板或必须在开始时创建登记。

同一事项的修复和反馈沿用原记录。记录位置可定位即可，无需新的编号系统、生成器或登记命令；已有 UUID 记录继续可用。显式使用现有工具时，其内部 UUID 和格式要求保持，不将“不强制日常登记”解释为改造工具协议。

同步核对实施、诊断、审查交付、规格整理、复盘及上下文交接入口，维护相关手册、映射和案例引用。正式规格仍在仓库中保存修订，记录引用它；普通小任务无须另写规格。保留必要来源摘要、决定理由、当前版本、未决项和下一步，不能由材料完整推导实施或远端写入授权。

本工单不解除证据工具或统计的现行启用要求，那分别由 03、02 负责；不能提前声称整套默认流程已经精简完成。该中间交付阶段仍适用的工具要求按其契约执行，避免中间版本出现相互矛盾的指令。

## 验收条件与验证

- [x] **A5：** 文档交付保留本地简短记录，能定位目标、修正来源、受检版本、命令结果、两轴结论和限制；不强制 UUID、起止时间或完整评估表。无可靠起止时间时可交付，但耗时保持未知。
- [x] **A5：** 合成任务带有既有 Issue／PR 引用时，记录仍在本机，执行过程中没有任何远端创建、追加、更新动作；无稳定来源链接时保留必要原话摘要。
- [x] **A6：** 使用同一事项的两个合成版本和局部反馈，验证反馈绑定实际版本及范围；新版本保持未确认，历史结论不覆盖，已修复的有效发现不变成误报。无反馈不算验收或零缺陷。
- [x] **A7：** 新上下文从记录及正式规格恢复，能发现旧摘要与最新来源修正的差异，保留未决项和下一步；不会因交接而新增授权或丢弃已有有效授权。
- [x] **A9 的记录部分：** 旧 UUID 目录及引用仍可读取，同一事项不重复计为多个样本；只用可靠、可比材料作量化复盘，缺失项保留未知，不补造历史时间或反馈。
- [x] 实施、诊断、审查交付、规格整理、复盘入口与共用规则对记录要求一致；更新受影响正文和链接，其余现行规则仍准确。关键决定按 ADR 约定保留来源和实际生效范围。

复用[流程回归](../../../docs/agents/workflow-regressions.md)的 W05（文档收尾）、W06（恢复及来源修正）、W08（沿用有效授权）、W09（历史发现），按实际影响组合最小试验，并加入“已有远端引用仍只留本地记录”和“无时间的复盘”场景。执行者使用隔离合成材料，裁定者核对实际记录、动作及版本，不能只看答复中的承诺。格式、链接与独立审查按[总览共同约束](../README.md#共同约束与交接)执行；没有浏览器验收需求。真实使用后的复盘效果留待自然反馈，不因一次试验通过就宣称提升。

## 依赖与交接状态

- **前置依赖：** 无。记录路径可以在现有检查及审查机制上独立落地，与 02 不互相阻塞；共享正文的编辑须协调并复查集成差异。
- **材料充分性：** 已明确；无阻断性设计缺口。
- **执行授权：** 规格 S7 已授权本地实施与验证；沿用该授权，不向远端写入。
- **交给 03：** 简短记录约定及实际样例、反馈与交接试验、适用版本和两轴结论。03 负责将其接入不启用证据及统计的完整任务路径并作最终验收。
