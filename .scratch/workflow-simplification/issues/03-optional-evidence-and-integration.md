# 03 按需使用证据工具并验收完整默认流程

## 来源与决定

来源为[流程精简规格](../../../docs/specs/workflow-simplification.md)的 S1–S6、默认流程、“可选工具与审查材料”及 A1–A9；规格基线为 `cd117913753e341d5c47adc2085502a0f5690b52`。

已确认默认路径是“核对目标与基线 → 修改及必要检查 → 独立审查与修正 → 提交并简短交付”。仅因涉及代码、从检查进入审查或切换上下文，不强制创建证据声明、快照和统计。明确选择复用旧检查结果且需要机器判断版本适用性时，按需启用现有证据工具。

现状见[证据版本规则](../../../docs/agents/change-workflow.md#证据版本与检查配置)、[维护手册](../../../docs/MAINTENANCE.md#每次改动)及[证据工具说明](../../../docs/agents/task-evidence.md)：代码、检查器和流程规则任务默认使用工具。工具本身仍使用合法任务 UUID、声明和快照，检查版本及命令结果；工具通过不证明声明完整、授权、人工验收或需求正确。没有需用户决定的机制缺口。

## 交付结果与约束

使普通任务可以直接执行适用检查，利用 02 固定材料并独立审查，利用 01 留下简短本地记录后交付。共用规则统一工具启用条件，实施、诊断、审查及其他入口、手册、工具说明、保障映射与回归引用同步维护，避免另一个入口恢复强制登记。

工具可选不等于验证可选。目标、规则、源码、测试、依赖或检查配置变化时，重跑受影响检查并复查；最新失败、中断或未完成不能被旧通过掩盖。高风险变更仍前置核对验收及失败场景；缩小检查收集或覆盖须对照旧基线审查。

显式选择证据工具时保留现有接口、内部 UUID、声明范围、运行及 `verify` 契约、快照与历史引用。不会为了普通路径无需 UUID 而删除工具参数。未声明的依赖仍须由独立审查发现；过期、缺失、失败或未完成均不能作为当前通过，不新增证据封装或统一任务命令。

本工单同时承担最终联动验收：核对 01、02 与本项的连接，复用适用局部结果并补查集成差异，给出完整 A1–A9 的证据对应及剩余限制。正式规格存仓库、交付记录存本机，不因已有 Issue／PR 触发远端补充。

## 验收条件与验证

- [ ] **A1、A2、A5：** 在隔离临时仓库完整完成普通代码小改动及纯文档交付，实际运行适用检查、独立两轴审查、提交并留下可追溯本地记录；不创建任务 UUID、声明、证据快照或统计样本，也不以未启用工具为由拒绝交付。
- [ ] **A3：** 检查或审查后分别改变相关目标／规则、源码／测试／依赖、配置，能辨认受影响结果并完成相应补查和复查；最终记录对应实际版本。失败或未完成后不得退用旧成功，无关且仍有效的证据可保留。
- [ ] **A4：** 显式选用工具复用结果时保留当前契约：相关输入变化使结果失效，未变化的有效结果按现有规则复用；缺失、最新失败、中断和配置漂移不能通过最终核验。声明遗漏的依赖仍由审查识别并要求补声明、验证与复查。
- [ ] **A8：** 高风险合成变更在实施前核对目标、保留条件、错误路径及验证方式；以删除检查或缩小收集范围掩盖原有失败的补丁被识别，不能仅凭新检查通过接受。
- [ ] **A6、A7：** 01 的本地记录能承接 02 的发现编号、修正和复查版本；跨会话读取最新来源及反馈后继续，旧版本局部验收不扩展到新版本，不凭材料齐备启动未授权实施。
- [ ] **A9：** 未选用工具的普通路径与明确启用证据／统计的专项路径均可运行；旧任务、快照和统计材料保持可读取与引用，未知信息不回填。只在隔离合成副本检验，不修改真实历史。
- [ ] 对[总览覆盖表](../README.md#整体验收归属)逐项关联实际验证与限制，完成集成版本的 Spec 与 Standards 审查。相关文档、技能和规则映射没有残留矛盾；ADR 说明已落地决定及保留边界，不把案例通过当作真实长期效果。

复用[流程回归](../../../docs/agents/workflow-regressions.md)的 W04、W05、W06、W07、W09、W10，结合前两项证据补查连接及受影响场景，新增 A1 的完整默认路径。使用现有[证据工具测试](../../../test/task-evidence.test.mjs)验证选择工具后的契约；统计兼容证据复用 02，版本变化时补查。独立执行者只取得提示、材料和规则，裁定者核对动作及产物；只读回放不能声称完整修改、检查、审查、提交路径通过。

运行适用非浏览器测试、`pnpm format`、`pnpm check`、`pnpm format:check`；发布前完整测试要求保持。所有试验使用临时副本与合成数据，不访问真实招聘平台、求职工作区或外部服务，不运行浏览器或 `pnpm verify`，不改变 CI。真实日常任务的收益与复盘效果只通过后续自然记录观察，不为填表额外索取确认。

## 依赖与交接状态

- **阻塞项：** [01 简短本地记录与可追溯反馈](01-local-delivery-records.md)、[02 独立审查不依赖统计启动](02-review-without-metrics.md)。没有这两项，完整默认路径仍会要求全量记录或统计启动，A1 无法成立。
- **材料充分性：** 目标、保留条件和验证安排已明确；依赖未解除不表示规格不完整。
- **执行授权：** 当前仅拆单，未授权实施；只有取得相应授权且前置结果完成并核对后，才能开始本工单。
- **最终交付：** 集成版本、A1–A9 的覆盖与剩余限制、两轴最终结论、简短本地交付记录。此工单承担整体验收，不将缺口留给未定义的后续工单。
