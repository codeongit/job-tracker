# 技能相关任务的分工

本页说明 [`writing-for-agents`](SKILL.md) 与当前环境中相关技能的职责，按实际任务选择所需入口。

- **`writing-for-agents`**：编写或审阅 Agent 指令文档，整理读取入口、规则层级和完成条件。需要细化技能正文的表达和信息组织时，也可按需参考。
- **`skill-creator`**：创建或更新技能，处理技能描述、目录结构、支持资源、界面元数据、调用策略和验证。
- **`openai-docs`**：需要确认 Codex 当前的技能发现、调用、配置字段或其他平台机制时，核实官方资料。

按当前环境提供的技能清单定位这些入口，每次只读取任务所需的技能与参考内容。普通 Agent 指令文档直接使用主文档；技能任务按上述职责选择入口，仅在出现对应问题时补充读取。平台配置和能力边界以当前官方资料为准。
